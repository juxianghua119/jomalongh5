# 祖玛珑「格纹奇遇」产品介绍 H5

## 项目规格

- 页面数量：9 页
- 移动画布：430 × 844
- 浏览方式：上下滑动、右侧页码跳转或键盘方向键
- 视觉语言：暖米白纸张、英伦格纹、超大衬线标题、满版产品图、细字号编辑文案
- 核心章节：封面 → 相遇 → 苦橙 → 香调结构 → 柑橘与蜂蜜 → 香草苏格兰 → 香气档案 → 限定礼盒 → 结尾

## 交互内容

- 页面滚动吸附与逐屏入场动画
- 顶部阅读进度与右侧页码导航
- 第 7 页可切换苦橙、柑橘蜂蜜、香草苏格兰三款香气档案
- 心愿清单按钮与礼盒按钮反馈
- 结尾跳转与限定礼盒收藏入口

## 文件说明

- `index.html`：H5 主文件
- `styles.css`：视觉样式与移动端适配
- `script.js`：页面导航、香气切换与交互反馈
- `assets/`：产品图素材
- `previews/`：9 张单页预览
- `preview-full.png`：9 页完整长图
- `preview-overview.png`：3 × 3 页面总览

本作品为数字 UI 课程概念设计，非祖玛珑品牌官方页面。
